# Retenção de registros

Autor: [[LLM]]

Fonte sintética original para demonstração. Todos os fatos abaixo são fictícios.

No laboratório fictício Jardim Aurora, os registros de medição são mantidos por 7 dias.
O relatório semanal usa somente contagens agregadas. O exemplo não coleta dados pessoais.
A retenção curta reduz o volume de dados do simulador; não é uma regra geral para outras instalações.
