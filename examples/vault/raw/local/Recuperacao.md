# Recuperação de configuração

Autor: [[LLM]]

Fonte sintética original para demonstração. Todos os fatos abaixo são fictícios.

No laboratório fictício Jardim Aurora, a configuração é copiada diariamente para um arquivo local separado.
Para recuperar a configuração, interrompa o simulador, restaure a última cópia conferida e reinicie o simulador.
O exercício verifica a restauração a cada mês. A cópia não substitui o arquivo Markdown original.
